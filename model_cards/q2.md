# 问题2模型卡

> 状态：已确认；工程实现与论文表达以 docs/handoffs/q2_model_handoff.docx 为唯一模型与结果依据。

## 1. 题目目标

在非正交、小样本实验设计内，比较温度、Co 负载量、Co/SiO2:HAP 装料关系、乙醇进料条件和装料方式对乙醇转化率 \(X_{\mathrm{EtOH}}\) 与 C4 烯烃选择性 \(S_{\mathrm{C4}}\) 的条件响应差异；识别温度依赖、跨背景不一致及可直接识别的局部二因素非加性。

不以 C4 烯烃收率为本问响应；不建立统一预测模型，不做全局因素重要性排名或无重复单元格的交互显著性检验。

## 2. 输入与数据

- 主数据：data/raw/q1_attachment1.xlsx 的性能数据表，114 条温度记录、21 个催化剂组合。
- 解析因素：\(\omega_{\mathrm{Co}},m_c,m_h,m_q,m_{\mathrm{cat}},\rho,q_{\mathrm{EtOH}},z,T\)。
- A/B 编号只定位实验组；A11 为 50 mg 1 wt% Co/SiO2 加 90 mg 石英砂、无 HAP，\(\rho\) 未定义。
- 未实测温度保持缺失；原始 0 为真实实验结果；其余产物选择性只作总和完整性检查。
- 不使用附件2。

## 3. 已确认模型

模型名称：**基于温度分层匹配与跨背景效应对比的催化因素影响分析**。

1. 在 21 个组合共有的 \(250,275,300,350\ ^\circ\mathrm{C}\) 上计算端点组内差
   \[
   D_{T,i}^{(R)}=R_i(350)-R_i(250),\quad R\in\{X_{\mathrm{EtOH}},S_{\mathrm{C4}}\}.
   \]
2. 对普通含 HAP 组合，以
   \[
   \bm{x}_i=(\omega_{\mathrm{Co},i},m_{\mathrm{cat},i},\rho_i,q_{\mathrm{EtOH},i},z_i)
   \]
   为因素向量；研究 \(F\) 时固定其余四个因素，程序自动枚举严格匹配块。
3. 多水平块按共同实测温度作等权边际分解
   \[
   R_{h\ell}=\mu+\alpha_h+\gamma_{\ell\mid B}+e_{h\ell},
   \]
   逐温度曲线为主证据，\(\gamma\) 仅为块内等权摘要。
4. 对同一 \(F:u\to v\) 的多个背景，计算
   \[
   \Delta_{R,b}^{F:u\to v}(T)=R(T,F=v,B_b)-R(T,F=u,B_b)
   \]
   并仅在各背景共同实测温度上比较。
5. 自动搜索其它三因素固定、两因素各两水平且四格齐全的局部结构；在百分点加法尺度计算二阶对比 \(I(T)\)，并作删一温度敏感性。

## 4. 固定结构与校验

- 严格匹配块数：Co 负载量 2、总装料量 3、配比 1、乙醇进料 5、装料方式 2。
- 跨背景复现的同对比族共 6 类：\(\omega_{\mathrm{Co}}:1\to5\)、\(m_{\mathrm{cat}}:100\to400\)、\(q_{\mathrm{EtOH}}:0.9\to1.68\)、\(0.3\to1.68\)、\(1.68\to2.1\)、\(z:\mathrm{I}\to\mathrm{II}\)。
- 完整局部四格仅有 \((m_{\mathrm{cat}},q_{\mathrm{EtOH}})\)：A8/A12/A3/A1，及 \((q_{\mathrm{EtOH}},z)\)：A12/A9/B1/B5。
- 250→350 ℃时，两个响应均为 21/21 正增量，平均增量约为 24.46、15.30 个百分点。
