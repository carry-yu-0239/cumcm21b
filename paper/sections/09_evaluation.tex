\section{模型评价与改进}

本文针对四个问题分别建立了温度响应分析、催化因素影响分析、收率优化和实验设计模型。各模型均根据数据结构选择适当复杂度的方法，并通过边界检查、稳定性分析或实验结构约束进行检验。

\subsection{模型优点}

\begin{enumerate}
  \item \textbf{充分利用实验设计结构。} 本文没有将附件1的 114 条温度记录简单视为独立样本，而是区分组内温度变化与组合间因素差异，使模型与催化实验的分组结构保持一致。
  \item \textbf{模型复杂度与样本规模匹配。} 针对单组合仅有少量温度观测的特点，问题一采用低自由度经验模型；问题二采用严格匹配和局部对比，避免小样本条件下过度拟合。
  \item \textbf{结论具有明确适用范围。} 对于因素影响分析，本文保留比较背景、共同温度和离散水平等限制条件，不将局部响应差异扩展为无条件因果关系。
  \item \textbf{验证过程较为完整。} 本文结合留一预测、物理边界检查、删一温度敏感性分析等方法，对模型稳定性进行检验。
\end{enumerate}

\subsection{模型不足}

\begin{enumerate}
  \item 由于题目提供的实验数据主要为离散条件下的观测结果，未覆盖的温度、进料条件和催化剂组合区域不能由当前模型可靠外推。
  \item 附件1大部分实验条件缺少重复测量，因此无法独立分离实验随机误差，部分统计意义上的显著性判断受到限制。
  \item 问题二中的严格匹配方法依赖已有实验组合结构；若新增实验覆盖完全不同的因素区域，需要重新建立匹配关系。
\end{enumerate}

\subsection{模型改进方向}

\begin{enumerate}
  \item 在关键因素反转区域增加重复实验，可进一步估计实验误差并开展更严格的统计检验。
  \item 若获得更多正交设计实验数据，可在保留实验结构约束的基础上建立更系统的响应面模型。
  \item 对问题四新增实验，可结合已有模型的不确定区域设计补充实验，提高后续优化结果的可靠性。
\end{enumerate}
