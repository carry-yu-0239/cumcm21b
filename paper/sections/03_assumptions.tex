\section{模型假设}

\subsection{问题一}

本节假设仅约束问题一的经验趋势分析，不延伸为对后续问题的事实判断。

\begin{enumerate}
  \item 仅在单个催化剂组合内部研究温度响应，不把不同催化剂组合混合为同质独立样本。
  \item 在各组合已有实验温度覆盖区间内，低自由度经验函数可作为趋势近似；该近似不是化学机理方程，也不用于大幅区间外外推。
  \item 附件未提供同一“催化剂组合--温度”条件下的重复测量，因此不能独立估计纯实验误差。模型误差分析仅用于趋势量化和小样本诊断，不作依赖重复误差的强显著性结论。
  \item 乙醇转化率和 $\mathrm{C}_4$ 烯烃选择性均处于 0--100\% 的物理范围；若经验函数在完整实验温度覆盖区间内明显出界，其可信度相应降低。
  \item 附件2的 7 行是同一次实验的不等间隔时间观测，保留原始时间顺序；不将其视为普通独立横截面样本，也不采用复杂时间序列模型。
\end{enumerate}

\subsection{问题二}

\begin{enumerate}
  \item 附件1的数值直接作为实验观测使用；未记录温度仅表示未实验，数值 0 为真实实验结果，不补值、不插值，也不因局部非单调而机械删点。
  \item 严格匹配只针对题目给出并纳入分析的主要实验因素，所得为实验范围内的条件响应差异，不作超出原设计的因果外推。
  \item 同一催化剂组合的多个温度点属于组内观测；跨组合比较只在实际共同温度上进行。
  \item 差分和局部二阶对比均定义在百分点加法尺度。由于温度--因素水平单元格无独立重复，不将非加性偏差解释为纯实验随机误差，也不作普通交互显著性检验。
\end{enumerate}
